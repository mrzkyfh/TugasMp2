┌─────────────────────────────────────────────────────────────┐
│ METODE 1: TRANSFER VIA KABEL USB (PALING MUDAH)            │
└─────────────────────────────────────────────────────────────┘

1. Hubungkan HP Android ke Mac dengan kabel USB

2. Buka Android File Transfer (download di: android.com/filetransfer)

3. Di Mac:
   - Buka Finder
   - Tekan: Cmd + Shift + G
   - Paste: /Users/muhammadrizky/Documents/mobile/duolingo_clone/instalasi/android/
   - Drag file "fluenta-app.apk" ke folder Download di HP

4. Di HP Android:
   - Buka aplikasi "Files" atau "File Manager"
   - Masuk ke folder "Downloads"
   - Tap file "fluenta-app.apk"
   - Jika muncul peringatan, tap "Settings" → Enable "Allow from this source"
   - Tap "Install"
   - Tap "Open" untuk membuka aplikasi

═══════════════════════════════════════════════════════════════
  ⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Install Blocked" atau "Can't Install Unknown Apps"
   ✅ Solusi:
      Settings → Security → Install unknown apps → 
      Pilih aplikasi (Files/Chrome) → Enable

❌ "App not installed"
   ✅ Kemungkinan:
      - Storage penuh (butuh minimal 100 MB)
      - APK corrupt (download ulang)
      - Android terlalu lama (minimal Android 5.0)

❌ "Parse Error"
   ✅ Solusi:
      - Download ulang file APK
      - Pastikan file tidak corrupt
