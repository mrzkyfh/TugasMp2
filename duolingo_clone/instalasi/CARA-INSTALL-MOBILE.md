## 📲 Cara Install di HP Android

### **Metode 1: Transfer via Kabel USB (Paling Mudah)**

1. **Hubungkan HP ke Mac dengan kabel USB**

2. **Buka Android File Transfer** (jika belum ada, download di: https://www.android.com/filetransfer/)

3. **Copy file APK ke HP:**
   - Buka Finder
   - Tekan `Cmd + Shift + G`
   - Paste: `/Users/muhammadrizky/Documents/mobile/duolingo_clone/instalasi/android/`
   - Drag file `fluenta-app.apk` ke folder Download di HP

4. **Di HP Android:**
   - Buka aplikasi **Files** atau **File Manager**
   - Masuk ke folder **Downloads**
   - Tap file `fluenta-app.apk`
   - Jika muncul peringatan "Install from Unknown Sources":
     - Tap **Settings**
     - Enable **Allow from this source**
     - Kembali dan tap file APK lagi
   - Tap **Install**
   - Tunggu proses instalasi selesai
   - Tap **Open** untuk membuka aplikasi

## ⚠️ Troubleshooting

### **"Install Blocked" atau "Can't Install Unknown Apps"**

**Solusi:**
1. Buka **Settings** di HP
2. Cari **Security** atau **Privacy**
3. Cari **Install unknown apps** atau **Unknown sources**
4. Pilih aplikasi yang Anda gunakan untuk install (Files, Chrome, dll)
5. Enable **Allow from this source**

### **"App not installed"**

**Kemungkinan penyebab:**
1. **Storage penuh** - Hapus file yang tidak perlu (butuh minimal 100 MB)
2. **APK corrupt** - Download ulang file APK
3. **Versi Android terlalu lama** - Aplikasi ini membutuhkan Android 5.0 (Lollipop) atau lebih baru

### **"Parse Error"**

**Solusi:**
1. Download ulang file APK
2. Pastikan file tidak corrupt
3. Cek versi Android Anda (minimal Android 5.0)
